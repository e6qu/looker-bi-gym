<p>A data source acts as a conduit between the data in an external platform or product, such as a database or spreadsheet, and the charts and controls in a Data Studio report. When you create a new report in Data Studio, you either add an existing <em>data source</em>, or create and add a new one. You can add more data to the report at any time.</p>

<p>The following sections explain how data sources fit into the big picture of Data Studio.</p>

<p><a name="data-model"> </a></p>

<h2 id="data_model" data-text="Data model" tabindex="-1">Data model</h2>

<p>Having a consistent definition for the metrics and dimensions that are shared across your business provides a common platform for data analysis.</p>

<p>Data sources provide the structure (schema) of the fields you or other report editors can use to create your reports. The data source is where you <a href="/data-studio/model-your-data">model your data</a>: for example, by creating calculated fields, adding parameters, and adjusting data types.</p>

<p><a name="data-sources-and-connectors"> </a></p>

<h2 id="data_sources_and_connectors" data-text="Data sources and connectors" tabindex="-1">Data sources and connectors</h2>

<p>Data sources use <em>connectors</em> to fetch your data from a specific platform, system, or product. You can use free connectors built by Google to access data such as Google Sheets, Google Ads, Google Analytics, and other Google Marketing Platform products, and more. You can also use connectors built by Data Studio partners through the <a href="https://developers.google.com/looker-studio/connector/">Community Connectors developer program</a>.</p>
<aside class="note"><strong>Note:</strong><span> Community connectors may cost money to use. If you have issues using a community connector, please contact that connector&#39;s developer directly.</span></aside>
<p>Visit the <a href="https://datastudio.google.com/data">Connector Gallery</a>.</p>

<p><a name="how-fetch"> </a></p>

<h2 id="how_and_when_data_sources_fetch_data" data-text="How (and when) data sources fetch data" tabindex="-1">How (and when) data sources fetch data</h2>

<p>Most data sources maintain a <strong>live connection</strong> to your data. Your data remains in the underlying dataset and is not imported into Data Studio except as needed to answer a specific request. That data is kept only temporarily.</p>
<aside class="note"><strong>Note:</strong><span> The data freshness option lets you set how often a particular data source will request fresh data. Until that threshold is reached, Data Studio will try to answer queries that are issued by the report from the data in memory. Answering queries with data that&#39;s already in memory can be much faster than fetching the data from the underlying dataset. Learn more about <a href="/data-studio/manage-data-freshness">managing data freshness</a>.</span></aside>
<p>For even faster performance, you can use an <strong>extracted data source</strong>. The <a href="/data-studio/extract-data-for-faster-performance">Extract data connector</a> creates a static snapshot of your data. The extracted data is stored securely in Data Studio, and you can update the snapshot whenever you want.</p>

<p><strong>File upload data sources</strong> let you import CSV data into Data Studio. By using a file upload data source, you can visualize information not otherwise supported by the other connectors. File upload data sources behave in many ways like extracted data sources, except you can&#39;t update them automatically. You must import new data manually.</p>

<p><a name="control-access-to-the-data"> </a></p>

<h2 id="control_access_to_the_data" data-text="Control access to the data" tabindex="-1">Control access to the data</h2>

<p>Access to the data that is provided by a data source is handled by <strong>data credentials</strong>:</p>

<ul>
<li><p><strong>Owner&#39;s credentials</strong> uses the credentials of the data source owner to authorize access to the dataset. This option lets you share reports that use this data source without requiring report viewers to have their own access to the underlying dataset.</p>
<aside class="special"><strong>Important:</strong><span> Before sharing a report or data source that uses Owner&#39;s credentials, be sure that you trust the person or persons with whom you share them.</span></aside></li>
<li><p><strong>Viewer&#39;s credentials</strong> require anyone who attempts to view the data that is provided by this data source to have their own access to the dataset.</p></li>
<li><p><strong>Service account credentials</strong> use a special type of Google account that is intended to represent a non-human user that can authenticate and be authorized to access your data.</p></li>
</ul>

<p>Learn more about <a href="/data-studio/data-credentials">data credentials</a>.</p>

<h3 id="filter_data_by_email_address_of_the_viewer" data-text="Filter data by email address of the viewer" tabindex="-1">Filter data by email address of the viewer</h3>

<p>Filtering a data source by viewer email address lets you provide &quot;row-level&quot; security over the data. Only the records in your data containing the signed-in viewer&#39;s email appear in the report.</p>

<p><a href="/data-studio/filter-by-email-address">Learn more</a>.</p>

<p><a name="embedded-vs-reusable-data-sources"> </a></p>

<h2 id="embedded_versus_reusable_data_sources" data-text="Embedded versus reusable data sources" tabindex="-1">Embedded versus reusable data sources</h2>

<p>Data sources can be either <em>embedded</em> or <em>reusable.</em> Reports can include both embedded and reusable data sources.</p>

<p><strong>Data sources that you create while editing a report are embedded</strong> in the report. To edit an embedded data source, you do so within that report. Embedded data sources make collaborating on reports and data sources easier. Anyone who can edit the report can also edit the data source as well as modify its connection. When you share or copy the report, any embedded data sources are shared or copied as well.</p>

<p><strong>Data sources that you create from the home page are reusable</strong>. You can reuse these data sources in different reports. Reusable data sources let you create and share a consistent data model across your organization. Only people with whom you share the reusable data source can edit it. Only the owner of the data source&#39;s credentials can modify the connection.</p>

<blockquote>
<p>To see whether the data sources in a report are embedded or reusable:</p>

<ol>
<li><a href="/data-studio/edit-a-report">Edit your report</a>.</li>
<li>In the menus, select <strong>Resource &gt; Manage added data sources</strong>.</li>
</ol>
</blockquote>

<p><a name="share-and-copy-data-sources"> </a></p>

<h2 id="share_and_copy_data_sources" data-text="Share and copy data sources" tabindex="-1">Share and copy data sources</h2>

<p>When you share or copy a report, all of its embedded data sources are shared or copied along with it. You don&#39;t need to share embedded data sources separately from the report. This means that other report editors can modify the data source.</p>

<p>Reusable data sources aren&#39;t copied or shared when you copy or share a report. If you want someone else to be able to modify a reusable data source, then you must share it with them explicitly.</p>

<p>Note that you don&#39;t need to share a reusable data source in order for viewers of the report to see the data, or for editors to use the fields provided by the data source to create charts and controls in the report.</p>

<p><a href="/data-studio/invite-others-to-your-reports">Learn more about sharing reports and data sources</a>.</p>
