# What three evidence items make a risk-decision BI metric BCBS 239-reviewable?

## Front

What three evidence items make a risk-decision BI metric BCBS
239-reviewable?

## Back

Source-to-metric data lineage (which serving view and base tables feed
it), a named owner / reviewer accountable for the definition, and a
reconciliation record per reporting date between the dashboard total and
an upstream control total. Visual styling is not in scope.
