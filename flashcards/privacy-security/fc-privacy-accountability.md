# What does GDPR accountability ask for in BI release evidence?

## Front

What does GDPR accountability ask for in BI release evidence?

## Back

A named controller / processor accountable for the BI source, recorded
evidence of the processing purpose, the field-minimisation decision, the
retention rule, and the access boundary. A dashboard whose sharing
register has no owner has no accountability evidence either.
