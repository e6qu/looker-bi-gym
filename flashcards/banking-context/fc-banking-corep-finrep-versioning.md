# What version evidence belongs in a COREP / FINREP-aligned BI dashboard release record?

## Front

What version evidence belongs in a COREP / FINREP-aligned BI dashboard
release record?

## Back

The reporting framework version, the validation rule version, and the
reference date, recorded next to each reported metric value per period.
Validation outcomes and capital ratios can change between framework
versions; period-over-period comparisons are only trustworthy when the
versions are stated explicitly for each period.
