# Which BI evidence items does a BCBS 239-style review expect for a risk-decision dashboard?

## Front

Which BI evidence items does a BCBS 239-style review expect for a
risk-decision dashboard?

## Back

Per-metric data lineage from source to dashboard, a named owner / reviewer
accountable for the definition, and a reconciliation record per reporting
date between the dashboard total and an upstream control total. Visual
styling is not in scope of the review.
