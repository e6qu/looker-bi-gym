# Cert-Track Coverage Matrix

Generated by `bun run coverage:cert-track`. Counts the number of
**authored items** (questions, flashcards, exam cards, terminology
entries) whose learner-visible text matches at least one
keyword for each cert-track topic. Frontmatter, `source_facts` lists,
and IDs are excluded so the matrix reflects assessment intent,
not metadata noise.

Item counts: quiz=78, flashcards=105, exam cards=16, terminology entries=150.

A `0` for a topic on a surface means no question / card / entry on
that surface tests or defines it. The script does not judge
quality; it only spots presence or absence of the keyword set.
